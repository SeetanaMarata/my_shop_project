# 🛍️ Shop Web Application

Веб-приложение интернет-магазина с использованием Bootstrap, Python и современных инструментов разработки.

## 🚀 Функциональность

- **Главная страница** - представление магазина и товаров
- **Каталог** - просмотр товаров с thumbnail изображениями
- **Категория товаров** - детальный просмотр товаров категории
- **Контакты** - форма обратной связи с обработкой POST-запросов

## 🛠️ Технологии

- **Backend**: Python 3.8+
- **Frontend**: HTML5, Bootstrap 5.3, CSS3
- **Инструменты**: Poetry, Git
- **Сервер**: Встроенный HTTP сервер Python

## ⚡ Быстрый старт

### 1. Клонирование и настройка

git clone <repository-url>
cd my_shop_project

Установить зависимости
poetry install

### 2. Запуск приложения

python src/shop_app/app.py
### 3. Открыть в браузере

http://localhost:8000
